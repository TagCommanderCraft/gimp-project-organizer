## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Project Library** | Organize GIMP project files with tags and completion status |
| **Script Manager** | Track installed Script-Fu scripts with description and usage |
| **Export Presets** | Save named export configurations for web, print and icons |
| **Color Profiles** | Document color space settings used per project or client |
